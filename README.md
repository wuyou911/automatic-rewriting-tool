# 长文转口播稿工具

把写好的长文（知乎文章、公众号长文）自动改写成分块、口语化、适合视频口播的脚本。

## 功能

- 输入一篇长文，输出适合口播的脚本
- 自动分块，每块 1-2 分钟
- 口语化改写，长句拆短
- 保留原文的观点、结构和情绪
- 保留语气词和停顿标记
- 输出 Markdown 格式，带小标题

## 技术栈

- Python
- Streamlit（网页界面）
- 质谱GLM4.7-Flash云端模型

## 怎么用

### 1. 安装依赖

```bash
pip install gradio requests
```

### 2. 确保 Ollama 在跑

```bash
ollama run qwen2.5:7b
```

### 3. 运行

```bash
python app.py
```

浏览器打开 `http://localhost:7860`，粘贴长文，点按钮，输出口播稿。
